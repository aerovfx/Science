# 📚 Hệ Thống Bài Học Micro:bit STEM Toàn Diện
# *Complete micro:bit STEM Lesson System*

> **Bộ kit:** Elecrow Crowtail STEAM Edu Kit for micro:bit  
> **Đối tượng / Target:** Học sinh lớp 6–12 (Grades 6–12)  
> **Tổng số buổi / Total sessions:** 36  
> **Ngôn ngữ / Language:** Song ngữ Tiếng Việt + English (Bilingual Vietnamese + English)  
> **Phiên bản / Version:** 1.0 — 2026-07

│   ├── slide01.md  →  slide36.md

    └── resources.md
