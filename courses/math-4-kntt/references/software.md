## 🧩 1. Phần Mềm Lập Trình Khối Trực Quan Scratch 3.0

### Cài Đặt
- Tải Scratch Desktop miễn phí cho Windows / macOS tại: [scratch.mit.edu/download](https://scratch.mit.edu/download)
- Hoặc sử dụng trực tiếp trên trình duyệt web: [scratch.mit.edu](https://scratch.mit.edu)

### Tác Dụng Trong Toán 4
- **Chương 1–4:** Lập trình nhân vật Scratch hỏi đố vui đọc số lớp triệu, tính giá trị biểu thức chữ và tìm hai số khi biết Tổng và Hiệu.
- **Chương 5–6:** Tạo hoạt ảnh trực quan hóa bánh Pizza chia làm các phân số bằng nhau.
- **Chương 8–9:** Vẽ hình bình hành, hình thoi bằng bút vẽ Scratch (Pen Extension) và vẽ biểu đồ cột đơn giản.

## 🐍 2. Cài Đặt Môi Trường Python Luyện Toán Tiểu Học

### Bước 1: Tải & Cài Đặt Python 3.10+
- Tải tại: [python.org/downloads](https://www.python.org/downloads/)
- Tích chọn **"Add Python to PATH"** khi cài đặt.

### Bước 2: Cài Đặt Thư Viện Vẽ Đồ Thị Biểu Đồ Matplotlib
Mở Terminal / Command Prompt và chạy lệnh:

```bash
pip install matplotlib pandas
```
