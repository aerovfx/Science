## 📐 1. Phần Mềm Hình Học Động GeoGebra Classic 6.0

### Cài Đặt
- Tải GeoGebra Classic 6 cho Windows / macOS / iPad tại: [geogebra.org/download](https://www.geogebra.org/download)
- Hoặc sử dụng trực tiếp trên trình duyệt web: [geogebra.org/geometry](https://www.geogebra.org/geometry)

### Tác Dụng Trong Toán 7
- **Chương III:** Dựng đường thẳng song song $a \parallel b$, kiểm chứng các góc so le trong và đồng vị.
- **Chương IV:** Dựng các tam giác bằng nhau theo c-c-c, c-g-c, g-c-g và kéo đỉnh kiểm chứng tính đúng đắn.
- **Chương IX:** Dựng 4 đường đồng quy (Trọng tâm G, Tâm nội tiếp I, Tâm ngoại tiếp O, Trực tâm H) trong tam giác nhọn, vuông, tù.

## 🐍 2. Cài Đặt Môi Trường Python & SymPy

### Bước 1: Tải & Cài Đặt Python 3.10+
- Tải tại: [python.org/downloads](https://www.python.org/downloads/)
- Tích chọn vào ô **"Add Python to PATH"** khi cài đặt.

### Bước 2: Cài Đặt Thư Viện Đại Số Ký Hiệu SymPy & Matplotlib
Mở Terminal / Command Prompt và chạy lệnh:

```bash
pip install sympy numpy matplotlib pandas
```
