# Đánh giá học tập

## Ba lớp đánh giá

1. **Đánh giá thường xuyên:** câu hỏi chẩn đoán, exit ticket, quan sát, code review.
2. **Đánh giá thực hành:** quy trình, an toàn, dữ liệu, giải thích kết quả.
3. **Đánh giá tổng kết:** bài kiểm tra, dự án, thuyết trình và bảo vệ.

Khi dùng kho đề, hãy tạo bản sao cho từng đợt kiểm tra, ghi rõ mục tiêu/ma trận và giữ đáp án trong khu vực giáo viên. Rubric dự án STEM cần được công bố cho học sinh trước khi bắt đầu.
