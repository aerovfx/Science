# Project context template

Use only for new projects or when repository instructions are missing/inadequate.

```markdown
# [Project name]

## Purpose and users
- Problem, audience, success outcome
- In scope / out of scope

## Architecture and stack
- Runtime, language, framework, versions
- Major modules and ownership boundaries
- Storage, integrations, deployment target

## Development rules
- Commands for setup, build, test, lint, typecheck
- Naming, formatting, error handling, logging
- Approved patterns and patterns to avoid

## Product and UI rules
- Design system, accessibility, responsive behavior
- Required loading, empty, error, and permission states

## Security and data
- Trust boundaries, authentication/authorization
- Sensitive data and secret handling
- Destructive-action and migration rules

## Quality and release gates
- Required tests and coverage expectations
- Performance/compatibility targets
- Review, branch, commit, CI/CD, rollout and rollback rules
```
